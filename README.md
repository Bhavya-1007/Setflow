# SetFlow

A simple, responsive Next.js homepage for an AI DJ set planner. Created by Bhavya Poddar. The product is in development; this version is an informational homepage with a decorative music illustration.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel later

Push this directory to a GitHub repository, then import it into Vercel. Vercel will detect Next.js; use the default build and output settings. This homepage requires no API keys or environment variables.

## Files

- `app/page.js` — homepage content and decorative illustration
- `app/globals.css` — dark theme, lime accents, and responsive layout
- `app/layout.js` — page title, description, and language
- `public/icon.svg` — favicon
